## Airline CRM Team 6
We are working on a Customer Relationship Management system for an airline company.


The system is a backend tool that helps airline staff manage both customer and business relationships in one place, instead of having them spread across separate tools. It maintains customer profiles, bookings, travel history, and service requests, while also functioning as a hub for the airline's B2B relationships, managing corporate/enterprise client accounts as well as interactions with partner businesses like catering and maintenance providers. Staff can also respond to inquiries and complaints, manage loyalty memberships, and send travel updates to customers.

This repository contains the team documents, project proposal, and source code for COE420 Software Engineering Lab.
