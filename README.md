## Airline CRM Team 6
We are working on a Customer Relationship Management system for an airline company.

The system maintains customer profiles, bookings, travel history, and service requests in one place instead of being spread across separate tools. Furthermore, the staff can also respond to inquiries and complaints, manage loyalty memberships, as well as send travel updates to their customers. 

This repository contains the team documents, project proposal, and source code for COE420 Software Engineering Lab.
